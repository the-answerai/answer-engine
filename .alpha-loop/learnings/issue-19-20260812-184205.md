## What worked

- Converted the canonical worker browser skill to `agent-browser` and kept both
  harness outputs generated from that single source.
- Pinned the browser CLI in the workspace and invoked it through `pnpm exec`,
  removing reliance on an ambient global command or network-time `npx` install.
- Made live verification instructions explicit while retaining Playwright only
  for automated E2E tests.
- Moved the browser profile under an ignored repository-local directory so a
  linked-worktree Codex agent can write it.

## What failed

- The previous setup synced `playwright-cli`, whose daemon attempted to write
  into a home cache outside the worker sandbox during #9.

## Reusable lesson

Tool choice and writable runtime state are part of verification posture, not
ambient environment assumptions. Assert them in repository tests before an
unattended UI issue begins.
