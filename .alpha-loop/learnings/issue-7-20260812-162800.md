## Corrections and surprises

The initializer chose the installed Claude CLI even though it was not
authenticated, so its optional scan output failed validation. An installed
harness is not necessarily an operational harness; authentication must be
validated before selection. The repository now uses authenticated Codex while
still synchronizing assets to Claude.

The first boundary regex used generic `role`, which incorrectly rejected ARIA
roles and OpenAI message roles. Paid role management now requires contextual
role-assignment language, while RBAC, teams, billing, permissions, Auth0/OIDC,
and Stripe remain prohibited in public product scopes.

The first CI run also revealed that the setup test still required the temporary
`.gitkeep` after the real issue learning file replaced it. Local verification
had run before that final artifact substitution. The regression now asserts the
tracked issue learning file itself, and the complete gate is rerun after every
final artifact change.
