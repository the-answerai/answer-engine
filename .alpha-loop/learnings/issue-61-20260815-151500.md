# Issue #61: unbounded raw archive growth and Cowork workspace sweep

- **Status:** Safety defect fixed and verified in an isolated issue worktree; the stable sync service remains disabled pending merge.
- **Observed impact:** The stable raw archive grew to approximately 1.0 TB in 3.5 days and continued writing until the host reported `ENOSPC`.
- **Root cause:** Immutable archive writes had no bundle, aggregate, or free-space ceiling, and Cowork recursively archived the directory surrounding a session instead of selecting explicit evidence.
- **Safety design:** Raw archives are content-addressed and reused across retries; writes are serialized across processes, bounded by configurable byte ceilings, preserve a minimum free-space reserve, validate source identity before and after streaming copies, and publish only an atomically completed staging directory.
- **Retention design:** Operators must first request a tenant-scoped preview. Only unreferenced archives are candidates, soft-deleted content continues to protect its evidence, an unchanged SHA-256 confirmation token is required, and authorization is recorded before removal. Retention never runs automatically.
- **Cowork design:** A fixed text-extension allowlist is applied only to relative `mountedFiles` entries in session metadata. Traversal, symlinks, unsupported formats, oversized artifacts, build output, dependency directories, copied transcripts, and unrelated workspace files are excluded.
- **Regression coverage:** Tests cover repeated and concurrent reuse, bundle and total limits, free-space reserve, manifest traversal, reference-aware retention confirmation, tenant and capability boundaries, and Cowork workspace/build/dependency/binary/oversize exclusions.
- **Verification:** Focused suites and `pnpm verify` passed, including boundary checks, lint, type-check, 351 passing tests, one intentionally skipped database integration test, and all production builds. An isolated Cowork smoke test reused one archive across two reads without touching the stable home.

Graphify remained excluded. No user archive was deleted, no npm package was published, and `master` was not pushed directly.
