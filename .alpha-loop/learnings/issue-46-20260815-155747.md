## What Worked
- Kept the default proposal deterministic and local, with model use behind an explicit opt-in and an enforced 50-record metadata ceiling.
- Stored the exact suggestions, decisions, apply results, timestamps, and audit entries so review, apply, undo, and reapply remain explainable.
- Used content-addressed suggestion IDs, unique plan fingerprints, existing slugs, and `ON CONFLICT DO NOTHING` memberships for idempotence.
- Deactivated plan-created taxonomy on undo and allowed only the same plan to reactivate it, preserving later user state without creating duplicates.

## What Failed
- The first browser accessibility pass exposed 4.01:1 contrast on the selected plan timestamp; a scoped text-color correction brought the second pass to zero violations.
- The pinned browser screenshot/close RPC stalled after semantic interaction, reproducing the known issue #44 daemon failure; bounded recovery preserved semantic, dimension, focus, motion, request, and axe evidence but no PNG.
- One full-gate route assertion returned 404 once after passing focused runs. It passed 20 immediate focused repetitions, the full server suite, and the final full gate without a code change.

## Patterns
- Treat organization as a persisted proposal state machine, not a direct model-to-mutation path.
- Fingerprint both sampled records and active taxonomy, then recheck inside the apply transaction before any mutation.
- Record only rows actually introduced by apply so undo cannot remove pre-existing memberships or user-owned taxonomy.
- Pair soft-deactivation with ownership metadata and updated-at guards when hard deletion could cascade into later user state.

## Anti-Patterns
- Do not trust model-provided record IDs, apply partial decision sets, reactivate inactive manual/other-plan taxonomy, or expose full content merely to generate categories.

## Suggested Skill Updates
- Add apply → undo → reapply → undo to reversible-workflow verification checklists.
- Treat documented model exposure limits as runtime security boundaries and test the exact upper bound.
