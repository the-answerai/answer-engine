# Support

Answer Engine is community-supported open-source software. The issue tracker
is for reproducible bugs, focused feature proposals, and documentation gaps.
Before filing, search existing issues and remove all credentials, personal
memory, transcripts, raw archive contents, and unrelated local paths from logs.

Use a GitHub Discussion when discussions are enabled and the question is about
setup or general usage. Otherwise, open an issue with the operating system,
Answer Engine version or commit, installation method, expected behavior,
actual behavior, and a minimal sanitized reproduction.

Maintainers do not promise response or resolution times for community support.
Security vulnerabilities must be reported privately through
[SECURITY.md](SECURITY.md). Conduct concerns follow
[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

The OSS repository includes the complete single-user product and all non-paid
workflows and UI. Only roles, RBAC, teams, billing, and permissions are
exclusive to the paid enterprise product. Requests involving those five
capability families may be redirected, while neutral extension interfaces and
local administration remain valid OSS topics.
