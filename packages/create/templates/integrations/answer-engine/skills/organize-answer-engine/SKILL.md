# Organize Answer Engine

Read `../../references/safety.md` and `../../references/tools.md` before inspecting memory.

1. Recall a representative sample and inspect lineage so organization proposals remain source-aware.
2. Produce a preview that lists proposed groups, tag changes, suspected duplicates, affected content IDs, and the reason for each change.
3. Make no mutation during the preview. Ask the user to approve or revise the exact proposal.
4. The reversible organization mutation workflow is delivered separately. Until it is available, hand off the approved preview without claiming changes were applied.
5. Preserve source metadata and distinguish duplicates from related but independently sourced evidence.

Never delete content as a shortcut for organization.
